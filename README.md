# Radio Barsaat

One-page community radio website template with a working tuner dial.

Demo: [https://sofikulxdd-web.github.io/tuner-radio-template/](https://sofikulxdd-web.github.io/tuner-radio-template/)

A fictional site for a community radio station. Turn the dial to find each show.

Plain HTML, CSS and JavaScript in one file, with no build step. It works on phones and respects reduced-motion settings.

More templates: [sofitechllc.com/stores](https://sofitechllc.com/stores/)
